WHAT THIS EXPERIMENT DOES

Seeing before predicting

1. The scene keeps its state private.

Every new trial generates different initial positions, impulses and physical parameters inside an isolated renderer. The observer receives only timestamped images and an opaque run identifier.

2. SAM finds the objects.

Actual SAM 3.1 requests produce masks. A local visual tracker follows those detected appearances between requests. When SAM is unavailable, we do not replace it with invented masks or simulator coordinates.

3. A separate model predicts motion.

A short-horizon motion fit uses recent observed positions to estimate the next 0.2 seconds, with an optional 0.5-second stress test. Changing the horizon starts a new trial and keeps the previous results separate. SAM is a segmentation model; it does not itself predict future forces or trajectories.

4. Predictions face later observations.

Each issued target is stored before its target time. When that time is observed, the recorded prediction is compared to the tracked position. Missing observations remain unscored.

The limits remain measurable.

The rendered scene is 3D, but this observer measures 2D image positions in pixels. It does not infer mass, material or full 3D geometry. Abrupt collisions, occlusion and chaotic changes can defeat short-term extrapolation. Displayed errors are against visual tracking, not an independent physical sensor.
