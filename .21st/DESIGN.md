# TWINFORGE — Visual intelligence studio

The active entry point uses dark graphite surfaces, lime actions, cyan observations and amber predictions. One large real rendered scene and one prediction challenge are the primary view. SAM evidence is a small actual image/mask preview; settings, usage and method live in native dialogs. All main product copy is English.

The prediction challenge is a temporal test, not a prerecorded animation: lock an immutable future target, pause the synthetic world, reveal the later frames, then display the measured visual error. The camera keeps running and records its outcome automatically. A user-triggered private random impulse changes motion without sending its force or velocity to the observer.

The source and observation overlay share an aspect-preserving surface. Mobile controls are at least44px, including a Lock prediction shortcut beside the scene. Use visible focus, reduced-motion support and native form semantics. A stopped or unavailable model must never look live.

SAM segments objects; a separate causal estimator forecasts 2D image motion. The API request accepts only the JPEG, concept and capture identity/time. Same-origin module separation is not a tamper-proof security boundary. Error is against subsequent visual tracking, sometimes interpolated, not independent physical ground truth.
