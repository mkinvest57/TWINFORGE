# TWINFORGE — Une décision. Deux futurs.

The main page compares two frozen simulated futures from the same supplied initial state. The central task is choosing one bounded intervention before a chain of collisions, testing sensitivity and recognizing when the tested action set has no passing solution. Water tanks and orbital loops are rejected product directions and removed from public navigation.

Four previously retrieved 21st components remain the native design sources, recorded in sources.json: sidebar, segmented tabs, measured outcomes and proposal stepper. The implementation uses native HTML/CSS/ES modules, local Three.js, and the existing Python backend. No React migration or copied sample metrics.

Dark workspace, compact navigation, high-contrast typography, orange reference/command and cyan intervention. The comparative scene is the primary content; controls must remain reachable on a phone. Rendering uses actual supplied planar states, identical clocks and immutable paths. The mobile scene stacks its branches. Motion starts on explicit replay, pauses in hidden tabs, and can be scrubbed.

The Meta journal shows actual bounded proposals and simulator outcomes, including failures. The local exhaustive search stays a separate reference. Known initial states, arbitrary energy threshold, instantaneous commands, sensitivity limits and synthetic scope must remain explicit. The camera stays a separate local 2D tracking tool.
